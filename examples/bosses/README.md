## Preparación del equipo bosses

Las cuatro fichas usan el mismo equipo de Minecraft. Si todavía no existe en tu mundo, créalo una sola vez con el bloque de impulso de la [sección de equipo del General](general-del-vacio.md#equipo-compartido). Después usa la línea `team join` de la ficha elegida. El equipo agrupa a las entidades; el armamento y la armadura se configuran por separado con `item replace`.

Los comandos de las fichas se presentan sin `/` inicial para bloques de comandos. Para ejecutarlos en el chat del juego, añade `/` delante.
