En las fichas, `NOMBRE_JUGADOR` indica dónde escribir el nombre exacto de quien recibirá el tag del poder. Sustitúyelo antes de ejecutar.

Los comandos de estas fichas se ejecutan en bloques de comandos y se presentan sin `/` inicial. Para ejecutarlos desde el chat del juego, añade `/` delante.

Este índice recoge los poderes documentados actualmente. Se ampliará cuando se recuperen otras implementaciones.
